## 1. 한 줄 정의
아이폰(핵심만) + 맥북(넓게, 항상 띄워둠)에서 보는 **읽기 전용** 개인 대시보드.
레트로 게임(게임보이 컬러 / 포켓몬 1~4세대 감성) 디자인, 비용 0원, 나만 봄.

## 4. 디자인 방향
- **팔레트**: 게임보이 컬러 느낌, 눈 안 아픈 채도. 4~6색 제한 팔레트. 그라데이션 금지.
- **레이아웃**: 카드 격자 금지. 게임 메뉴/대화창 같은 "창(window)" 구조. 폰은 1열 핵심, 맥북은 넓은 보드.
- **마스코트**: 사용자가 Gemini로 뽑은 이미지를 받아 **도트로 재구성**. 표정 2~3개(평소/할 일 많음/돈 부족) `[확인 필요: 이미지 전달, 크기]`
- **폰트**: 기본 폰트 금지. 아기자기한 한글 픽셀/둥근 폰트 후보: 갈무리(Galmuri), 네오둥근모, 둥근모꼴 (무료 라이선스 여부는 적용 전 재확인)
- **움직임**: 작은 반응만. 갱신 시 깜빡임, 숫자 바뀔 때 살짝 튐 정도.
- **말투**: 포켓몬 1~4세대 텍스트 톤 참고. 예) `▶ 이번 달 쓸 수 있는 돈은 123,000원!` / `할 일이 3개 남아있다!`
  - 단, 숫자 자체는 서술체 안 씌우고 그대로. 톤은 상태 문장에만.
- **금지 목록(사용자 지정)**: 이모티콘, 그라데이션, 카드 격자, 번역체, 사용자 고려 없는 UI, 일관성 없는 디자인.
- **IP 주의**: 포켓몬 스프라이트·로고·캐릭터 직접 사용 X. 분위기(UI 창, 폰트 감성, 말투)만 참고.
- **Impeccable**: 로컬 Claude Code에 플러그인으로 설치해 `critique`/`polish`/`audit` 돌림. 로컬로 옮긴 뒤 적용.

## 5. 기술 구조 제안 (0원)
```
[원본 데이터]                 [백엔드]                    [화면]
구글 시트 (돈·루틴·구독·D-day) ─┐
구글 캘린더 ───────────────────┼→ Google Apps Script 웹앱 → 정적 웹(HTML/CSS/JS)
할 일 (Google Tasks 또는 Todoist)┘   (JSON 하나로 묶어 반환)      Cloudflare Pages 또는 GitHub Pages
```
- **Apps Script를 쓰는 이유**: 시트·캘린더·Google Tasks를 API 키 없이 읽을 수 있고 무료. 코드는 레포에 같이 보관.
- **자동 갱신**: 브라우저가 N분마다 Apps Script 호출. 5분 주기면 하루 약 300회 → 무료 한도 안 (추정).
- **보안(나만 봄)**: 레포가 공개면 HTML도 공개됨. 그래서
  - 데이터 요청에 비밀 토큰 필요, 토큰은 기기당 1회 입력 후 로컬 저장(코드에 안 넣음), 또는
  - Cloudflare Pages + Cloudflare Access(무료 구간)로 구글 로그인 게이트 `[추정, 적용 전 무료 한도 확인]`
- **돈 데이터 원본**: 한국 은행 개인 무료 API는 사실상 없음(추정) → 구글 시트 수동 입력 전제. 폰에서 빠른 입력은 iOS 단축어 → 시트 추가로 보완 가능.

## 6. 단계
- **0단계 (지금)**: 남은 질문 확정, 시트 구조(탭·열) 먼저 고정 ← 작게 시작의 약점(나중에 데이터 구조 바꾸면 전부 손봄) 방지
- **1단계 MVP**: 돈 화면 1개. 시트 → Apps Script → 폰/맥북 레이아웃. 마스코트 도트 1종. 자동 갱신.
- **2단계**: 할 일 + 캘린더
- **3단계**: 루틴, 구독, D-day, 커리큘럼
- **4단계**: Impeccable critique 반복, 알림(필요 시)
