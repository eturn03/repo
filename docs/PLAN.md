# 개인 대시보드 계획 (v0.2)

> 2026-11-08. 질문·답변 2차 반영. `[확인 필요]` 표시는 아직 결정 안 된 항목.

## 1. 한 줄 정의
아이폰(핵심만) + 맥북(넓게, 항상 띄워둠)에서 보는 **읽기 전용** 개인 대시보드.
레트로 게임(게임보이 컬러 / 포켓몬 1~4세대 감성) 디자인, 비용 0원, 나만 봄.

## 2. 확정된 조건
| 항목 | 결정 |
|---|---|
| 기기 | iPhone + MacBook (기본 브라우저 Chrome. 사용자 로컬에 CLI로 띄우는 "aside" 브라우저도 있음 — 정체 미확인, 차단 요소 아님) |
| 형식 | 웹(PWA). 홈화면 추가로 앱처럼 사용. 위젯 X |
| 사용 방식 | 맥북에 계속 띄워둠 → 자동 갱신 필수 |
| 입력 | 대시보드에서 안 함. 원본(구글 시트 등)에서 따로 입력 |
| 알림 | 1차 제외. 나중에 필요 시 추가 |
| 비용 | 0원. 무료 API 연동은 OK. 월 구독 절대 X |
| 접근 | 나만 봄. 공개 X |
| 호스팅 | GitHub Pages (이 레포가 공개 레포라 무료). 레포 공개 = HTML 공개 → 데이터는 토큰으로 보호 |
| 유지보수 | 완성 후 수정은 Claude에게 맡김 → 설정은 최대한 단순하게 |
| 진행 | 작게 시작, 나중에 확장 |

## 3. 보여줄 것 (우선순위 순)
1. **돈** ← 1차 MVP. "쓸 수 있는 돈" 중심. 사용자가 로컬에 만들어둔 기존 작업물 받아서 구조 결정 `[대기: 사용자 집 도착 후]`
2. 할 일 → **Google Tasks**로 결정(미리알림 사용 안 함). 같은 구글 계정이라 Apps Script가 토큰 없이 읽음. 입력 UX가 아쉬우면 Todoist(무료)로 교체 가능.
3. 캘린더 → 아이폰 기본 캘린더에 연결된 **구글 계정 캘린더**. 공휴일(빨간날)은 표시, 기념일류("~~의 날")는 제외 `[해석 확인 필요]`
4. 루틴
5. 구독 결제일
6. D-day
7. Claude가 준 커리큘럼 `[확인 필요: 형태 — 주차별 체크리스트 / 긴 글 / 날짜 일정]`
8. (만들며 추가·삭제)

후잉 가계부는 사용 안 함.

## 4. 디자인 방향
- **팔레트**: 게임보이 컬러 느낌, 눈 안 아픈 채도. 4~6색 제한 팔레트. 그라데이션 금지.
- **레이아웃**: 카드 격자 금지. 게임 메뉴/대화창 같은 "창(window)" 구조. 폰은 1열 핵심, 맥북은 넓은 보드.
- **마스코트**: 사용자가 Gemini로 뽑은 이미지를 받아 **도트로 재구성** `[대기: 이미지 전달]`
  - 크기: 포켓몬 스프라이트 기준 **64×64** (3~4세대 전투 스프라이트 크기. 기억 의존, 적용 시 재확인). 화면에선 2~3배 정수 확대.
  - 표정 3종: 일반 / 기쁨 / 화남. 상태 매핑 예) 돈 여유·할 일 끝 → 기쁨, 예산 초과·마감 임박 → 화남, 그 외 → 일반.
- **폰트**: 기본 폰트 금지. 아기자기한 한글 픽셀/둥근 폰트 후보: 갈무리(Galmuri), 네오둥근모, 둥근모꼴 (무료 라이선스 여부는 적용 전 재확인)
- **움직임**: 작은 반응만. 갱신 시 깜빡임, 숫자 바뀔 때 살짝 튐 정도.
- **말투**: 포켓몬 1~4세대 텍스트 톤 참고. 예) `▶ 이번 달 쓸 수 있는 돈은 123,000원!` / `할 일이 3개 남아있다!`
  - 단, 숫자 자체는 서술체 안 씌우고 그대로. 톤은 상태 문장에만.
- **금지 목록(사용자 지정)**: 이모티콘, 그라데이션, 카드 격자, 번역체, 사용자 고려 없는 UI, 일관성 없는 디자인.
- **IP 주의**: 포켓몬 스프라이트·로고·캐릭터 직접 사용 X. 분위기(UI 창, 폰트 감성, 말투)만 참고.
- **Impeccable**: 로컬 Claude Code에 플러그인으로 설치해 `critique`/`polish`/`audit` 돌림. 로컬로 옮긴 뒤 적용.

## 5. 기술 구조 제안 (0원)
```
[원본 데이터]                 [백엔드]                    [화면]
구글 시트 (돈·루틴·구독·D-day) ─┐
구글 캘린더 ───────────────────┼→ Google Apps Script 웹앱 → 정적 웹(HTML/CSS/JS)
할 일 (Google Tasks 또는 Todoist)┘   (JSON 하나로 묶어 반환)      Cloudflare Pages 또는 GitHub Pages
```
- **Apps Script를 쓰는 이유**: 시트·캘린더·Google Tasks를 API 키 없이 읽을 수 있고 무료. 코드는 레포에 같이 보관.
- **자동 갱신**: **5분 주기** 확정. 하루 약 300회 → Apps Script 무료 한도 안 (추정).
- **보안(나만 봄) → 결정: 기기당 1회 토큰 입력 방식**
  - Apps Script 웹앱은 "누구나 접근"으로 열되, 요청에 비밀 토큰이 없으면 빈 응답.
  - 토큰은 코드·레포에 절대 안 넣음. 폰/맥북에서 첫 접속 때 1번 입력 → 브라우저 로컬 저장.
  - 고른 이유: 공개 레포 + GitHub Pages 조합에서 Claude가 코드만으로 전부 설정 가능. Cloudflare Access는 사용자가 Cloudflare 계정·도메인을 직접 만져야 함.
  - 나중에 더 강하게 하고 싶으면 Cloudflare Access(무료 구간)로 교체 가능.
- **공휴일 판별**: 구글 "대한민국의 휴일" 캘린더에서 공휴일/기념일 구분이 되는지 구현 때 확인. 안 되면 공공데이터포털 특일 API(무료 키) 사용.
- **돈 데이터 원본**: 한국 은행 개인 무료 API는 사실상 없음(추정) → 구글 시트 수동 입력 전제. 폰에서 빠른 입력은 iOS 단축어 → 시트 추가로 보완 가능.

## 6. 단계
- **0단계 (지금)**: 남은 질문 확정, 시트 구조(탭·열) 먼저 고정 ← 작게 시작의 약점(나중에 데이터 구조 바꾸면 전부 손봄) 방지
- **1단계 MVP**: 돈 화면 1개. 시트 → Apps Script → 폰/맥북 레이아웃. 마스코트 도트 1종. 자동 갱신.
- **2단계**: 할 일 + 캘린더
- **3단계**: 루틴, 구독, D-day, 커리큘럼
- **4단계**: Impeccable critique 반복, 알림(필요 시)
