# 설치 안내 (한 번만)

순서대로 하면 된다. 막히면 Claude에게 화면 캡처를 보여주면 됨.

## 1. 구글 시트 만들기
1. 구글 시트를 새로 만든다. 이름은 자유.
2. 탭 이름을 `요약`으로 바꾸고 1행에 `항목`, `값`, `단위`를 적는다.
3. 2행부터 `쓸 수 있는 돈`, `이번 달 예산` 등을 적는다. 자세한 구조는 `docs/SHEET.md`.

## 2. 스프라이트 폴더 만들기 (구글 드라이브)
1. 드라이브에 폴더를 하나 만든다. **공유하지 않는다.**
2. 이미지를 `normal.png`, `happy.png`, `angry.png` 이름으로 넣는다. (일반 / 기쁨 / 화남)
3. 폴더를 열었을 때 주소창의 `folders/` 뒤 글자가 폴더 ID다. 복사해 둔다.

## 3. Apps Script 붙이기
1. 시트 메뉴에서 **확장 프로그램 > Apps Script**.
2. 왼쪽 `Code.gs` 내용을 지우고, 이 레포의 `apps-script/Code.gs` 내용을 통째로 붙여넣는다.
3. 왼쪽 톱니바퀴(프로젝트 설정) > **"편집기에서 appsscript.json 매니페스트 파일 표시"** 체크.
   `appsscript.json`이 나타나면 이 레포의 `apps-script/appsscript.json` 내용으로 바꾼다.
4. 프로젝트 설정 맨 아래 **스크립트 속성 > 속성 추가**:
   - `SPRITE_FOLDER_ID` = 2단계에서 복사한 폴더 ID
5. 편집기 위쪽 함수 목록에서 `setupToken`을 고르고 **실행**. 처음엔 권한 허용 창이 뜬다.
   실행 로그에 `새 토큰: ...`이 나온다. **이 토큰은 비밀번호처럼 보관한다.** 어디에도 올리지 말 것.

## 4. 웹앱으로 배포
1. 오른쪽 위 **배포 > 새 배포 > 유형: 웹 앱**.
2. 실행 계정: **나**, 액세스 권한: **모든 사용자**.
   (주소를 알아도 토큰이 없으면 빈 응답만 간다.)
3. 배포 후 나오는 **웹 앱 URL**(…/exec)을 Claude에게 준다. → Claude가 `js/config.js`에 넣음.
   이 주소는 공개돼도 괜찮다. 토큰만 비밀.

> 코드를 고친 뒤에는 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전**으로 다시 배포해야 반영된다.

## 5. GitHub Pages 켜기
1. GitHub 레포 페이지 > **Settings > Pages**.
2. Source: **Deploy from a branch**, Branch: 작업 브랜치(또는 main) / `/ (root)` > Save.
3. 1~2분 뒤 나오는 주소가 대시보드 주소.

## 6. 기기마다 처음 한 번
1. 폰·맥북에서 대시보드 주소를 연다.
2. 3단계에서 받은 토큰을 입력.
3. 폰: Safari 공유 버튼 > **홈 화면에 추가**. 맥북: Chrome 주소창 오른쪽 설치 아이콘(있으면).

## 미리보기 (설치 전)
- 대시보드 주소 뒤에 `?demo`를 붙이면 예시 숫자로 화면만 볼 수 있다. 화면 아래에 "예시 데이터로 보는 중" 표시가 뜬다.
- 로컬에서 스프라이트까지 보려면 레포 안에 `local-sprites/` 폴더를 만들고 이미지 3개를 넣는다. 이 폴더는 깃에 안 올라간다.
