# 설치 안내

막히면 화면을 캡처해서 Claude에게 보여 주면 된다. 토큰(서버 비밀번호)은 Claude에게도, 어디에도 보내지 않는다.

## 이미 끝난 것 (2026-11-10)
- 구글 시트 "돈관리"에 서버 프로그램 "돈 보드 서버"가 붙어 있고 웹 앱으로 배포돼 있다.
- 권한 허용과 토큰 만들기(`setupToken`)를 했다. 토큰은 네 메모에 있다.
- 맥에서 연결 시험을 통과했다.

## 1. 웹앱 열기 (폰·맥북 각각 처음 한 번)
1. 주소 `https://eturn03.github.io/repo/` 를 연다.
2. "비밀 토큰" 칸에 토큰을 붙여넣고 **확인**. 이 기기에 저장돼서 다음부터는 안 묻는다.
3. 아이폰: Safari 아래 공유 버튼 → **홈 화면에 추가**. 맥북: 크롬 주소창 오른쪽 설치 아이콘(있으면), 외부 모니터에 띄워 둔다.

토큰을 잃어버리면: 시트 메뉴 **확장 프로그램 → Apps Script** → 왼쪽 `Code.gs` → 위쪽 함수 칸에서 `setupToken` → **실행** → 아래 실행 로그에 다시 나온다.

## 2. 아이폰 위젯 (Scriptable, 무료)
1. 아이폰에 Scriptable 앱이 있다(이미 설치됨). 앱을 열면 **돈보드 위젯** 스크립트가 보인다. iCloud로 맥에서 넘어온 것이다.
2. **돈보드 위젯**을 한 번 눌러 실행 → 서버 주소는 미리 채워져 있으니 **저장** → 토큰을 붙여넣고 **저장**. 작은 위젯 미리보기가 뜨면 성공.
3. 홈 화면 빈 곳을 길게 누름 → 왼쪽 위 **편집 → 위젯 추가** → Scriptable → 작은 크기 → 추가.
4. 추가된 위젯을 길게 누름 → **위젯 편집** → Script를 **돈보드 위젯**으로 고른다. "When Interacting"은 그대로 둔다(누르면 웹앱이 열린다).
5. 잠금 화면에도 쓰려면: 잠금 화면을 길게 누름 → 사용자화 → 잠금 화면 → 위젯 칸 → Scriptable → 같은 방법으로 **돈보드 위젯**을 고른다.

위젯은 아이폰이 정한 때에만 새로 고친다(보통 15분~1시간). 방금 넣은 지출이 바로 안 보일 수 있어서 숫자 아래에 "몇 시 기준"이 적혀 있다. 연결이 안 되면 마지막 숫자와 "연결 안 됨"이 나온다.

주소나 토큰을 바꿔야 하면 Scriptable 앱에서 **돈보드 위젯**을 실행 → **주소·토큰 다시 넣기**.

## 3. 마스코트 그림 (선택)
드라이브 폴더 **대시보드 스프라이트**에 `normal.png`, `happy.png`, `angry.png`, `ghost.png`를 넣으면 보드의 상태 문장 옆에 나온다. 폴더는 공유하지 않는다. 그림이 없어도 숫자는 그대로 나온다.
