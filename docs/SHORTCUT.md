# 아이폰 단축어: 사기 전 판정 → 기록

> 예전 메뉴바의 "결제 전 확인 / 입력"을 아이폰 단축어로 옮긴 것.
> 대시보드는 보기만 하고, 돈 입력은 이 단축어가 구글 시트 "돈관리"의 지출 탭에 한다.
> 먼저 `docs/SETUP.md` 1~4단계(Apps Script 배포)를 끝내야 한다.

## 흐름
1. 금액을 친다.
2. 판정이 뜬다: "2,000원을 쓰면 오늘까지 쓸 수 있는 돈이 1,300원 남는다." (건당 한도 이상이면 경고 한 줄 추가)
3. **샀어** → 결제 수단 고르기 → 메모(기본값 "식비") → 지출 탭에 기록 → "기록했다! … 오늘까지 쓸 수 있는 돈은 …원." 알림.
   **안 샀어** → 아무것도 안 남김.

기록 규칙: 식비는 기록한다. **교통비는 고정비로 잡혀 있으니 기록하지 않는다.**
신용카드로 기록하면 자산 탭의 카드 미결제액이 자동으로 늘어난다.

## 준비물
- 웹앱 주소 (`…/exec`로 끝남, SETUP.md 4단계)
- 토큰 (SETUP.md 3단계 `setupToken` 실행 로그)

토큰은 이 단축어 안에만 넣는다. 단축어를 남에게 공유하지 말 것(토큰이 같이 나감).

## 만들기
단축어 앱 > 오른쪽 위 **+** > 이름 "돈 쓰기". 아래 동작을 위에서부터 차례로 추가한다.
(동작 이름은 기억에 의존해 적은 것이라 iOS 버전에 따라 조금 다를 수 있다. 검색창에 앞 글자를 치면 나온다.)

| 순서 | 동작 | 설정 |
|---|---|---|
| 1 | **텍스트** | 웹앱 주소를 붙여넣기 |
| 2 | **변수 설정** | 이름 `주소`, 입력 = 텍스트 |
| 3 | **텍스트** | 토큰을 붙여넣기 |
| 4 | **변수 설정** | 이름 `토큰`, 입력 = 텍스트 |
| 5 | **입력 요청** | 입력 유형 **숫자**, 프롬프트 `얼마 쓸 거야?` |
| 6 | **변수 설정** | 이름 `금액`, 입력 = 제공된 입력 |
| 7 | **URL의 콘텐츠 가져오기** | URL = `주소` 변수. "더 보기"를 펼쳐서 방법 **POST**, 요청 본문 **JSON**, 필드 3개 추가: `token` = `토큰` 변수, `view` = `check`, `amount` = `금액` 변수 |
| 8 | **사전 값 가져오기** | 키 `message` |
| 9 | **메뉴에서 선택** | 프롬프트 = `사전 값` 변수. 항목 2개: `샀어`, `안 샀어` |

`샀어` 아래에 넣을 동작:

| 순서 | 동작 | 설정 |
|---|---|---|
| 10 | **목록** | 항목 3개: `신용카드`, `체크카드`, `현금·페이` |
| 11 | **목록에서 선택** | 프롬프트 `뭐로 냈어?` |
| 12 | **변수 설정** | 이름 `수단`, 입력 = 선택된 항목 |
| 13 | **입력 요청** | 입력 유형 **텍스트**, 프롬프트 `메모`, 기본 답변 `식비` |
| 14 | **변수 설정** | 이름 `메모`, 입력 = 제공된 입력 |
| 15 | **URL의 콘텐츠 가져오기** | URL = `주소`, 방법 **POST**, 요청 본문 **JSON**, 필드 5개: `token` = `토큰`, `view` = `add`, `amount` = `금액`, `memo` = `메모`, `method` = `수단` |
| 16 | **사전 값 가져오기** | 키 `message` |
| 17 | **알림 보기** | 내용 = `사전 값` |

`안 샀어` 아래는 비워 둔다. 마지막의 "메뉴 끝" 뒤에도 아무것도 넣지 않는다.

> `수단`의 `신용카드` 글자는 정확히 이대로 적어야 카드 미결제액에 더해진다.

## 빨리 여는 법 (열기 귀찮음 방지)
- **뒤로 탭**: 설정 > 손쉬운 사용 > 터치 > 뒤로 탭 > 이중 탭 > "돈 쓰기". 폰 뒷면을 두 번 두드리면 바로 실행된다.
- **잠금 화면·홈 화면**: 단축어 위젯을 두거나, 단축어 공유 버튼 > 홈 화면에 추가.
- 아이폰 15 Pro 이상이면 **동작 버튼**에 연결해도 된다.

## 안 될 때
- "금액을 숫자로 입력해 줘"가 뜨면: 7·15번의 `amount` 필드가 `금액` 변수인지 확인.
- 알림에 아무것도 안 뜨면: 토큰이 틀린 것. 3번 텍스트를 다시 붙여넣기.
- 그래도 안 되면 단축어 화면을 캡처해서 Claude에게 보여주기.
