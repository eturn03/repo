# 구글 시트 구조 (초안 v0.1)

> 2026-11-09. **돈 관리 작업물을 받기 전 초안.** 받으면 `돈_` 탭들을 확정하고 v1.0으로 고정한다.

## 원칙
- 대시보드는 탭 이름과 **1행 제목**을 그대로 읽는다. 2행부터가 데이터.
- 이름이 `_`로 시작하는 탭(예: `_메모`)은 대시보드로 안 보낸다.
- 화면에 보이는 숫자는 전부 시트에서 수식으로 계산한다. 화면은 계산하지 않고 보여주기만 함.
- 돈 상세 기록은 어떤 모양이든 괜찮다. 대시보드는 `요약` 탭만 본다.

## 탭 목록

### `요약` (1단계, 지금 쓰는 탭)
| 항목 | 값 | 단위 |
|---|---|---|
| 쓸 수 있는 돈 | (수식) | |
| 이번 달 예산 | (수식 또는 숫자) | |
| 이번 달 지출 | (수식) | |
| 남은 날 | (수식) | 일 |

- `항목`, `값`은 꼭 있어야 함. `단위`는 비우면 `원`.
- **`쓸 수 있는 돈`**: 화면의 큰 숫자. 꼭 있어야 함.
- **`이번 달 예산`**: 있으면 HP 바(남은 비율)가 나온다. 없으면 숫자만.
- 나머지 행은 "이번 달 기록" 창에 위에서부터 순서대로 나온다. 행을 더하거나 빼면 화면도 따라감.

### `돈_…` (1단계, 작업물 받고 확정)
수입·지출 기록, 고정비 등. 기존 작업물 구조를 최대한 살린다. `요약` 탭이 여기서 수식으로 끌어옴.

### `루틴` (3단계)
| 이름 | 요일 | 시간 | 메모 |
|---|---|---|---|
- 요일: `월,수,금` 처럼 쉼표로. 매일이면 `매일`.

### `구독` (3단계)
| 이름 | 금액 | 결제일 | 주기 | 메모 |
|---|---|---|---|---|
- 결제일: 매월이면 숫자(예: `15`), 매년이면 날짜.
- 주기: `매월` 또는 `매년`.

### `D-day` (3단계)

|---|---|

### `커리큘럼` (3단계)
| 주차 | 항목 | 완료 | 메모 |
|---|---|---|---|
- 완료: 체크박스(삽입 > 체크박스).

## 시트에 없는 것
- 할 일: Google Tasks에서 읽음 (2단계).
- 일정·공휴일: 구글 캘린더에서 읽음 (2단계).
