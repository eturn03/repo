# 카드 대조 (주 1회)

돈 규칙과 시트 구조의 기준은 `tasks/plan.md`(3절 돈 규칙, 4.2 시트 탭). 실제 금액·시트 주소는 `local-notes/값_v2.md`와 `local-notes/돈관리_인계.md`에만 있다. 레포·커밋 메시지에 금액이나 시트 주소를 적지 않는다. 사용자에게는 한국어 반말, 결과부터, 코드 용어 없이 말한다.

## 준비
1. `local-notes/값_v2.md`에서 시트 ID와 카드 규칙(결제일, 사용 기간)을 읽는다.
2. Google Sheets 커넥터로 `설정!A1:C40`, `지출!A1:H2000`, `자산!A1:E20`을 읽는다. 쓰기 전에 대조 전 숫자를 적어 둔다: 웹앱 `?demo`가 아닌 실제 화면이나, 지출·설정 값으로 `apps-script/Calc.js`의 `Calc.summary`를 Node에서 돌려 오늘까지 쓸 돈, 이번 달 남은 돈, 교통 차감, 월 상환 가능액을 낸다.
3. 대조 범위: `마지막대조일` 다음 날부터 오늘까지. 비어 있으면 이번 주기 첫날부터.

## 1. 카드 앱 화면 읽기
- 화면마다 건별로 날짜, 금액, 가맹점, 승인/취소를 표로 옮긴다. 읽기 어려운 칸은 추측하지 말고 "읽기 어려움"으로 두고 사용자에게 묻는다.
- 어느 카드 화면인지(수단 이름: `설정`의 `수단` 목록 중 하나)를 확인한다. 모르면 묻는다.
- 화면에 "결제 예정 금액"이나 "이용 금액 합계"가 있으면 같이 적는다(카드 미결제 기준 금액).

## 2. 지출 탭과 맞추기
- 같은 수단에서 날짜가 같거나 하루 차이이고 금액이 같은 행이면 이미 있는 것이다. 카드 승인일과 입력 날짜가 하루 어긋날 수 있다.
- 지출 탭에만 있고 카드에 없는 행: 현금·다른 수단이면 그대로 둔다. 같은 카드인데 카드에 없으면 지우지 말고 표에 "카드에 없음"으로 보고하고 사용자에게 묻는다.
- 취소 건: 원래 결제가 지출 탭에 있으면 그 행을 지우는 대신 금액을 음수로 한 줄 더 넣고 메모를 "취소"로 둔다(기록이 남게).

## 3. 빠진 결제 넣기
- 교통은 묻지 않고 분류 `교통`으로 넣는다. 교통으로 보는 것: 셔틀 가맹점 "(주)오케이관광", 교통카드·티머니·버스·지하철·후불교통 표시.
- 나머지는 분류를 묻는다. `AskUserQuestion`으로 한 번에 4건까지, 선택지는 `설정`의 `분류` 목록에서 가장 그럴듯한 것을 첫 선택지에 "(추천)"으로 둔다. 가맹점 이름을 질문에 같이 적는다.
- 행 모양(지출 탭 열 순서): `id, 날짜, 금액, 분류, 수단, 메모, 출처, 입력시각`
  - id: `rc` + 대조 날짜 + 순번, 예 `rc20261117-01` (영문·숫자·`-`만, 6~64자. 서버의 중복 막기가 이 칸을 본다)
  - 날짜: `YYYY-MM-DD` 글자로 넣는다(시트가 날짜로 읽는다)
  - 메모: 가맹점 이름. 출처: `대조`. 입력시각: 지금 `YYYY-MM-DD HH:mm:ss`
- `append_values`로 지출 탭 끝에 한 번에 붙인다.

## 4. 설정·자산 갱신
- `교통대조일`: 카드 내역에서 교통이 확인된 **마지막 날**로만 올린다. 교통카드 내역은 며칠 늦게 찍힐 수 있어서, 화면에 아직 안 찍힌 날까지 올리면 교통 차감이 실제보다 작게 잡힌다.
- `자산` 탭의 그 카드 행: 금액 = 화면의 결제 예정(미결제) 금액, 기준일 = 오늘. 메모의 "임시"는 실제 값으로 맞췄으면 지운다.
- `마지막대조일`: 오늘.

## 5. 확인과 보고
1. 커넥터로 지출 탭과 설정을 다시 읽어 넣은 행과 날짜가 맞는지 본다.
2. `Calc.summary`로 대조 뒤 숫자를 다시 낸다.
3. 사용자에게 표로 보고한다:

| 항목 | 대조 전 | 대조 뒤 |
|---|---|---|
| 오늘까지 쓸 수 있는 돈 | | |
| 이번 달 남은 돈 | | |
| 교통 (실제 + 예상) | | |
| 월 상환 가능액 | | |

그리고 넣은 건 목록(날짜, 금액, 분류, 가맹점), 카드에 없던 앱 기록, 읽기 어려웠던 칸을 적는다. 보드는 5분 안에 저절로 바뀐다(바로 보려면 새로고침).

## 하지 않는 것
- 이체·결제 같은 돈 이동. 상환이 필요해 보여도 계산만 보여 준다.
- 구독을 줄이자는 제안을 먼저 꺼내는 일.
- 카드 번호·계좌 번호 전체를 어디에 옮겨 적는 일. 가맹점 이름과 금액만 쓴다.
