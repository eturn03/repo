# 일정 타이머 (macOS)

하루 일정을 텍스트로 한 번 붙여넣으면, 화면에 떠 있는 **메이플스토리(빅뱅 전) 스타일 상태바**로 지금 할 일과 남은 시간을 보여주는 개인용 앱.

- 사용 언어: Swift + SwiftUI (Apple의 앱 개발 언어/화면 도구)
- 필요 환경: macOS 13 이상 (Sequoia 15.8.1에서 사용 예정), Apple 개발자 계정 불필요

---

## 설치 (처음 한 번)

### 1. 터미널 열기
`⌘ + Space` → `터미널` 입력 → Enter.

### 2. 개발 도구(Command Line Tools) 설치
터미널에 아래 한 줄을 붙여넣고 Enter.

```bash
xcode-select --install
```

- 설치 창이 뜨면 **설치** → 약관 동의 → 끝날 때까지 기다리기 (수 분).
- `already installed` 라고 나오면 이미 설치된 것이니 다음 단계로.

### 3. 코드 내려받기
1. 브라우저에서 이 저장소 GitHub 페이지로 이동.
2. 왼쪽 위 브랜치 선택 버튼에서 `claude/sweet-babbage-cmhykr` 선택.
3. 초록색 **Code** 버튼 → **Download ZIP**.
4. 다운로드 폴더에서 ZIP을 더블클릭해 압축 풀기.

### 4. 빌드 + 설치
터미널에 아래 두 줄을 붙여넣고 Enter. (폴더 이름이 다르면 다운로드 폴더에서 실제 이름을 확인해서 바꿔줘)

```bash
cd ~/Downloads/repo-claude-sweet-babbage-cmhykr
bash build.sh
```

- 마지막에 `✅ 설치 완료`가 나오고, 화면 아래쪽에 상태바가 뜨면 성공.
- 앱은 `~/Applications/ScheduleTimer.app`(내 홈 폴더 안의 응용 프로그램)에 설치됨.

### 5. 처음 실행하면
- 화면 아래쪽에 상태바가 뜨고, 일정이 없으면 설정 창이 같이 열림.
- "로그인 항목이 추가됨" 알림 → 정상. 재부팅해도 자동 실행되게 하는 설정.
- 메뉴 막대에는 모래시계 아이콘만 있음 (상태바를 숨겼을 때 다시 켜는 용도).

## 화면 보는 법

| 칸 | 의미 |
|---|---|
| LV | 오늘 끝낸 블록 수. 블록을 끝까지 하거나 "완료"를 누르면 +1 (건너뛰기는 X) |
| 첫째 줄 | 지금 할 일 (빈 시간이면 `다음: OO`) |
| 둘째 줄 | 닉네임 |
| HP | 오늘 일정(첫 블록 시작~마지막 블록 끝) 중 남은 시간 `[남은/전체]` |
| MP | 남은 블록 수 `[남은/전체]` |
| EXP. | 지금 블록 진행률. `남은시간[퍼센트]`. 100%가 되면 레벨업 이펙트 + 효과음, 다시 0%부터 |

- 상태바는 **끌어서 옮길 수 있고**, 위치는 기억됨.
- **돋보기 버튼** → 설정 창 (일정 입력, 블록 조작, 크기·닉네임 등).

## 사용법

1. 돋보기 버튼 → 설정 창.
2. 일정을 복사한 뒤 **클립보드에서 붙여넣기** (또는 입력창에 `⌘V`).
3. **오늘 / 내일** 선택 → **저장**.
   - 형식이 틀린 줄은 빨간 글씨로 몇 번째 줄인지 알려주고, 나머지는 등록됨.
   - 저장하면 기존 일정은 새 일정으로 교체됨.

### 일정 형식
한 줄에 한 블록, **시작-끝 할일** 순서. 24시간제.

```
09:00-10:30 영어공부
10:30-10:45 휴식
10:45-12:00 과제
```

- `9:00-10:30`, `09:00 - 10:30`, `09:00~10:30`, 앞에 `- ` 글머리표 → 모두 인식
- 빈 줄, `#`으로 시작하는 줄 → 무시
- `23:00-01:00`처럼 자정을 넘기는 블록 가능

**Claude에게 일정 부탁할 때 붙일 문장:**
> 각 줄을 `HH:MM-HH:MM 할일` 형식으로만 출력해. 24시간제, 시간순, 겹치지 않게, 다른 설명 없이.

### 블록 조작 (진행 중인 블록이 있을 때 버튼이 보임)
| 버튼 | 선택지 |
|---|---|
| 완료 | 다음 블록 바로 시작(이후 일정 앞당김) / 원래 일정 유지(빈 시간). 레벨업 O |
| 건너뛰기 | 위와 같음. 목록에 "건너뜀"으로 표시. 레벨업 X |
| +5분 / +10분 | 이후 일정 뒤로 밀기(빈 시간을 먼저 쓰고 겹치는 만큼만) / 다음 블록 줄이기 |

- 바뀐 블록은 주황색으로 **원래 시간**과 함께 표시.
- **원래 일정으로 되돌리기** 버튼으로 전부 원상 복구.

### 기타 설정 (설정 창 아래쪽)
- 닉네임
- 상태바 크기 (0.6배~3배, 맥북·외부 모니터에 맞게 조절)
- 상태바 보이기/숨기기
- 레벨업 미리보기 (이펙트·효과음 테스트)
- 스킨 폴더 열기 / 스킨 다시 불러오기 / 블록 시작 소리 고르기
- 로그인 시 자동 실행, 종료

### 메이플 원본 파일 넣기 (스킨·효과음)
설정 창의 **스킨 폴더 열기** → 열린 폴더(`~/Library/Application Support/ScheduleTimer/Skin`)에 파일을 복사 → **스킨 다시 불러오기**.

| 파일 | 가져온 곳 | 쓰임 |
|---|---|---|
| `StatusBar.img` | UI.wz | 상태바 바탕·HP/MP/EXP 게이지·숫자를 게임 원본 이미지로 |
| `Game.img` | Sound.wz | 레벨업 소리(`LevelUp`), 블록 시작 소리(설정 창에서 고르기) |

- 파일이 없으면 코드로 그린 모양과 macOS 기본음을 씀.
- 이 폴더의 파일은 내 맥에만 있고 GitHub 저장소에는 올라가지 않음.

### 음악 (메이플 BGM 셔플)
설정 창의 **음악 폴더 열기** → 열린 폴더(`~/Library/Application Support/ScheduleTimer/Music`)에 파일을 넣고 → **다시 불러오기** → **재생**.

- `Bgm00.img` 같은 Sound.wz의 BGM 파일: 안에 든 곡을 전부 찾아서 목록에 넣음
- mp3 / m4a / wav / aiff 파일도 가능
- 모든 곡을 한 번씩 무작위 순서로 돌고, 다시 섞어서 계속 재생
- 상태바 오른쪽 클릭 메뉴에서도 재생/일시정지, 다음 곡
- 설정 창에서 **음악 볼륨**·**효과음 볼륨** 따로 조절

### 직접 구한 소리 파일 쓰기
같은 폴더에 아래 이름으로 넣으면 Game.img 소리보다 우선 사용됨. 확장자는 mp3/wav/m4a/aiff.

| 파일 이름 | 재생 시점 |
|---|---|
| `levelup.mp3` | 블록이 끝날 때 (레벨업) |
| `blockstart.mp3` | 빈 시간이 끝나고 블록이 시작될 때 |

## 업데이트
새 버전 ZIP을 다시 받아서 **4단계**만 다시 하면 됨. (저장된 일정은 유지)

## 삭제
1. 메뉴 막대 창에서 **종료**.
2. 터미널에서:
```bash
rm -rf ~/Applications/ScheduleTimer.app ~/Library/Application\ Support/ScheduleTimer
```
3. 시스템 설정 > 일반 > 로그인 항목에 남아 있으면 제거.
